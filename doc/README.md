# TrinityCore documentation

Start with the [world database reference](world-database/README.md) for the installed master schema, table and column catalog, logical relationships, source enums, content-authoring guides, and operational diagnostics.

The reference is scoped to core revision 914a6f655c97 and TDB 1210.26091, captured on 2026-10-09. See its [coverage report](world-database/coverage.md) for independently unresolved field meanings.

For a practical walkthrough, start with the [quest authoring hub](world-database/guides/quests.md): build a simple quest, then configure objectives, rewards, daily/repeatable behavior, chains, and eligibility.

For zone behavior, see the [zone scripting guides](zones/README.md), beginning with [Exile's Reach](zones/exiles-reach.md) and its [ship-to-beach sequence](zones/exiles-reach-ship-to-beach.md).
